# 海洋背景

在整个 Harness 窗口后方铺一层日间海面。画面里的船不是为了装饰而存在，它们对应正在运行的工作。

## 画面

海盗大船代表当前主会话的主 Agent，在世界坐标持续向右航行，镜头水平跟随。海面和岛屿留在世界坐标。每个子 Agent 各对应一艘小艇，包含更深层子 Agent：工作开始时从左侧驶入并伴航，明确结束、失败或取消后向右驶出。等待输入时小艇留在队里。

帆表示工作状态。主 Agent 的回合正在进行时满帆，待命或等待输入时收起一部分帆；帆态不靠 token 静默时长判断。大船始终保持航行。

海浪只由 token 吞吐驱动。统计缓存输入、未缓存输入、缓存写入与输出四项 token 增量，每秒采样，指数平滑后按饱和曲线映射浪高。费用不参与驱动。主浪采用 196、132、86 个场景单位的三组波长，降低包络变化频率和高频法线细纹强度；船只浮动与海面使用同一份波浪参数。

普通浪顶保留蓝绿色，去掉按高度叠加的固定阳光色，并减弱浅色染色和天空反射。白沫强度在平滑吞吐超过 100 token/秒后逐步开启，400 token/秒时达到最大；还需经过浪面高度、坡度和两层碎片遮罩筛选。白沫最高混色比例为 34%，颜色保留少量海水底色，避免整片浪头泛白。船尾和水线接触泡沫独立保留。实际观感已通过实景验收。

海风同时最多两条，近、远各一条，每条风线本身从屏幕左边延伸到右边，端点位于画面之外。全线保持一道宽缓弧线，屏幕可见部分相对两端连线的弧高约为屏幕高度的 1%～3%，没有连续波形或多次转弯。每阵风持续 4.2～6.2 秒，右端先响应，左端延后 0.9～1.6 秒，中段使用独立的鼓起与回落过程；各端位移为所属高度范围的 60%～85%，避免整条线同步上下平移。先用 0.7 秒淡入，结束前用 1 秒淡出，再间隔 0.6～1.8 秒换位出现。远层首次出现比近层晚 1.2～2.4 秒，之后各自使用独立随机节奏。横向位置固定，近层总宽 6～8 个屏幕像素，远层 4～6 个屏幕像素，包含柔化边缘。天空前用偏深色，海面前用偏浅色，近层从船前掠过，远层保留场景遮挡。本轮改动已通过实景验收。

沿途景观有低平沙洲、带植被的绿岛和露出岩壁的岩岸岛，首次入画和回收时随机选择轮廓、大小与朝向。沙洲放在主船后面的远景层，深度坐标不大于 -120。礁石以低矮石群为主，偶尔出现细高海蚀石柱，可以从船前方经过。景物固定在世界坐标，随距离加雾，并避开船队航道和镜头净空区。远处偶尔有海鸟掠过。浅蓝色二维岛岸与山脊剪影已移除。

## 操作

右下角的按钮打开设置，可调整显示海面、背景强度、播放、画质、摄像机距离、摄像机高度、镜头左右偏移和摄像机俯仰角。里程读数与设置按钮放在同一个停靠容器里横向排列，两者不会再叠在一起。背景本身不接管鼠标，只有设置面板接受操作。

摄像机距离控制与主船的水平距离，范围 20 至 100，默认 44；摄像机高度控制距海面的高度，范围 2 至 40，默认 4.8。数值使用场景单位。距离和高度只改变摄像机位置。俯仰角单独控制上下转动，范围 -30° 至 60°，默认 2.7°；负值向上，正值向下，0° 为水平。左右朝向与侧倾保持固定。调整立即生效，暂停时也可调整，设置会自动保存。

画质分均衡与高画质两档，均衡档以稳定 30 帧为目标，高画质档以 60 帧为目标。

窗口隐藏或最小化时渲染暂停，Agent 的运行不受影响。

设置按钮旁有只读航行里程。空白新会话页显示本机今日总数，第一条用户消息被接受并记录后改为显示当前船队累计值；查看子 Agent 时沿用主船队。里程按大船实际前进距离记录，暂停和隐藏期间不增加，关闭背景时隐藏。记录保存在本机 DSH 数据目录，分叉从创建时的原船队快照接续；这些行为已通过实机验收。

## 限制

主船使用 Maksim Batyrev 的 Stylized Pirate Ship，按 CC BY 4.0 使用并改动了帆与材质。插件随包附带的资产与署名见 THIRD_PARTY_NOTICES.md。

小艇使用 Sk1ttle 的 Row Boat，按 CC BY 4.0 使用。划艇没有帆，工作状态由桨的轻微摆动表达，不套用大船的帆态规则。

帆面通过在加载时为每面帆烘焙一个收帆形态实现，没有使用骨骼或布料模拟。方形帆挂在横桁上，从正侧视角看到的是帆的边缘，画面里呈现为几条窄面。
